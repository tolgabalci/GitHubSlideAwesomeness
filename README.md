# GitHubSlideAwesomeness

Keynote Slidedeck Test - A GitHub Pages site for presenting Keynote slides.

## Setup

This repository is configured to deploy to GitHub Pages automatically when changes are pushed to the `main` branch.

### Adding Your Keynote Slides

1. Export your Keynote presentation as HTML
2. Replace the `index.html` file with your exported HTML content
3. Add any supporting files (images, CSS, JavaScript) from your Keynote export
4. Push your changes to the `main` branch
5. Your slides will be available at your GitHub Pages URL

### Enabling GitHub Pages

To enable GitHub Pages for this repository:

1. Go to **Settings** → **Pages**
2. Under **Build and deployment**, select **GitHub Actions** as the source
3. The deployment workflow will automatically publish your site

## Viewing Your Presentation

Once deployed, your presentation will be available at:
`https://<username>.github.io/GitHubSlideAwesomeness/`
